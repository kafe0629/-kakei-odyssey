家計・オデッセイ資金管理 v5.8
光熱費・夫婦精算＋産休中家賃対応版

【家賃】
・通常の本人負担：45,000円
・妻の産休中：50,000円
・初期状態は「産休中」
・産休終了日は空欄のまま運用可能
・終了日を設定すると、その日より後の次回資金計算では通常家賃へ戻る
・15日の固定振り分けを動的計算
  自分のみずほ：貯金50,000円＋県民共済2,500円
  妻のみずほ：家賃50,000円（産休中）
  楽天銀行：教育資金10,000円
  NISA：開始月以降10,000円

【光熱費】
・ガス / 電気 / 水道を月ごとに保存
・毎月の請求総額を入力
・本人負担割合は初期50%
・ガス：妻のみずほ口座を初期設定
・電気：払込用紙を初期設定
・水道：支払者/方法を選択可能
・未払い / 支払済・未精算 / 精算済を管理
・妻へ精算する額 / 妻から受け取る額 / 差額を表示
・「今、八十二銀行に確保する光熱費」を支払管理へ自動反映
・本人の最終負担を月次「光熱費（本人負担）」へ反映可能
・JSONバックアップと安定版バックアップにも光熱費データを含む
