家計・オデッセイ資金管理 v6.5.1

v6.5 起動時0円表示の修正版です。

【原因】
v6.5で追加した「カード月次完全自動同期」の呼び出しは存在していましたが、一部の実装関数がファイルに入っておらず、起動中にJavaScriptが停止していました。画面の¥0は初期表示が残ったもので、通常は既存localStorageデータを消していません。

【修正】
・利用月自動同期の実装を追加
・請求月自動同期の実装を追加
・月次フォームへの反映を追加
・起動時同期に安全ガードを追加
・本当に破損したゼロ状態の場合は正常バックアップから自動復旧を試行
・v6.5の車総維持費、GO判定、資金段階、実績ペース等は維持

【GitHub Pages】
index.html / manifest.json / sw.js を3つとも上書きしてください。

【重要】
更新後、ホームが以前の金額へ戻るか確認してください。戻るまでは設定を保存したり初期化したりしないでください。
