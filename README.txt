家計・オデッセイ資金管理 v6.6
請求突合＋現金分離＋予算実績版

【1 請求突合チェック】
請求月ごとに、カード会社の請求額と登録済み明細を比較します。
・au PAY: 設定した締め日（現在15日）から支払月を計算
・イオン: 10日締め想定で請求月へ割当
・apollostation: billGroupを最優先、なければ10日締め想定
・請求調整/値引きは利用月からは除外したまま、請求突合には含める

既知データの検証:
2026年9月 apollostation 明細合計 20,197円 = 請求20,197円
2026年10月 apollostation 明細合計 2,769円
2026年10月 au PAY 明細合計 149円

【2 現金支出をカードと別管理】
月次の利用月画面で、日付・カテゴリ・内容・金額を登録できます。
カード自動同期はONのままでOKです。
現金はカード明細には混ぜず、変動生活費・履歴・CSVでは合算します。
光熱費は従来の本人負担欄を使うため、現金カテゴリには重複させません。

【3 予算 vs 実績】
全体生活費予算は「au PAY生活費 月間予算」を基準にします。
食費・日用品・コンビニ・外食娯楽・タバコ・その他をカード＋現金で集計。
ガソリンと光熱費は別枠表示です。
カテゴリ予算は設定画面で任意設定（0円=未設定）。

【バックアップ】
現金支出も正常バックアップ・安定版・JSONに含めます。
JSON versionは6.6へ修正しました。

【維持】
v6.5.1までのカード完全自動同期、車計画、GO判定、光熱費、採用中プラン等を維持。
