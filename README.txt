家計・オデッセイ資金管理 v7.0.3
コンビニ明細だけ「分割」表示版

【修正内容】
「分割」ボタンをコンビニ明細だけに表示するよう変更しました。

表示される例:
・ローソン
・ファミリーマート
・セブン-イレブン
・ミニストップ
・その他、カテゴリが「コンビニ」の明細

表示されない例:
・apollostation ガソリン
・apollostation 値引き
・日用品
・食費
・外食・娯楽
・その他

すでに分割済みの明細は、
カテゴリが後から変わっても「分割編集」を残すため、
いつでも分割内容を修正できます。

【既存仕様】
ローソン ¥1,000
→ タバコ ¥600
→ コンビニ ¥400

カード利用額は ¥1,000 のまま。
月次カテゴリだけ
・タバコ ¥600
・コンビニ ¥400
へ分離します。

【検証】
JavaScript構文: OK
5ページ構造: ['home', 'monthly', 'car', 'schedule', 'settings']
ローソン/コンビニ: 分割表示 OK
apollostation/ガソリン: 非表示 OK
apollostation/値引き: 非表示 OK
既存の分割済み明細: 分割編集表示 OK
