家計・オデッセイ資金管理アプリ

【内容】
・みずほ銀行残高、生活防衛資金150万円、購入目標350万円の進捗
・オデッセイ e:HEV ABSOLUTE・EX＋11.4インチナビのローン試算
・購入前／購入後の家計残額
・Money Forward MEから転記する月次記録（タバコを別表示）
・カード締め日／確定日／引落日
・口座の役割
・設定変更、JSONバックアップ／復元、CSV出力
・入力内容は端末のブラウザ内に保存

【iPhoneでアプリのように使う方法】
PWAとしてホーム画面に追加するには、index.html / manifest.json / sw.js の3ファイルを同じフォルダのままHTTPSで公開してください。
例：GitHub Pages、Cloudflare Pages、Netlify等の静的サイト公開サービス。
公開後のURLをiPhoneのSafariで開き、共有 →「ホーム画面に追加」を選択します。

【まず確認する場所】
設定画面に現在値を入れてあります。Money Forward MEの月次実績が揃ったら「月次」画面に入力してください。
