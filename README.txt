家計・オデッセイ資金管理 v6.8
月末締め・夫婦精算管理版

【妻との精算】
月ごとに家賃＋光熱費差額をまとめ、
・自分のみずほ → 妻のみずほ
・妻のみずほ → 自分のみずほ
の精算方向と金額を自動表示します。

「この金額で精算済みにする」で月ごとの精算状態を保存します。
精算後に金額が変わると「金額変更あり」と表示します。

【月末チェックリスト】
1. カード請求確認
2. 現金支出確認
3. 光熱費確認
4. 妻との精算完了
5. みずほ月末残高入力

1〜3は手動チェック、4〜5は自動判定です。
5項目すべて完了すると月締めできます。

【月締め】
締めると、その月の
・月次記録
・3カード利用集計
・よく使った店
・現金支出集計
・カード請求
・光熱費
・夫婦精算
・チェック状態
をスナップショットとして固定します。

締め済み月では、
・カード自動同期
・請求自動同期
・カード分類変更
などがあっても確定済み月の表示を変更しません。

また締め済み月の
・月次保存
・カード再反映
・請求保存/クリア
・現金追加/削除
・光熱費変更
を保護します。

必要な時だけ「締めを解除して再集計」で編集可能に戻します。

【予定ページ】
月末に
カード突合 → 現金 → 光熱費 → 妻との精算 → みずほ月末残高 → 月締め
の流れを追加しました。
