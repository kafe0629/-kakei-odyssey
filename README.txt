家計・オデッセイ資金管理アプリ v1.3

【v1.3変更点】
・ホームに「カード・口座 支払管理」を追加
・八十二銀行とauじぶん銀行の現在残高を入力可能
・au PAYゴールド / イオン / apollostation の次回請求額を入力可能
・au PAYゴールド分について、auじぶん銀行の現在残高を差し引いた「八十二→auじぶん 必要額」を自動計算
・イオン＋apollostation＋その他確保額を含め、八十二銀行で自由に使える金額を自動計算
・支払管理は端末内に保存し、JSONバックアップ/復元にも含める
・apollostation次回請求の初期値は、直近で確認済みの20,197円。支払後は実額に更新してください。

【更新方法】
GitHubリポジトリの index.html / manifest.json / sw.js / README.txt を同梱ファイルで上書きし、Commit changesしてください。
GitHub Pages反映後、ホーム画面アプリを完全終了して再起動してください。
