家計・オデッセイ資金管理アプリ v2.3

【v2.3変更点】
・スクリーンショットの完全自動判定を強化
・複数画像を一度に選択して、画像ごとに種類を判定
・対応：八十二銀行、みずほ銀行、auじぶん銀行、au PAYゴールド、イオンカード、apollostation
・みずほ/八十二/auじぶん銀行は残高表示エリアを再OCRし、取引明細を残高と誤認しにくくした
・認識結果画面に「画像名 → 判定された種類」を表示
・判定に失敗した画像だけ、従来どおり画像種類を指定して再読み取り可能

【使い方】
1. 「画像の種類」は自動判定のままにする
2. 「画像を選ぶ」で銀行・カードのスクショを複数選択
3. 自動判定結果と金額を確認
4. 正しければ「認識結果を反映」
5. 誤っている画像だけ種類を指定し、1枚で再実行

※ OCRは誤認識する可能性があります。必ず反映前に表示金額を確認してください。


[v2.3] 実際の7種類の銀行・カード画面に合わせてOCRを再調整。八十二銀行の支店/口座番号除外、auじぶん/au PAYの判定強化、利用可能額やポイントの除外、0円の正常認識を改善。
