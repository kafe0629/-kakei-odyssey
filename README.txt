家計・オデッセイ資金管理 v7.3.9
利用月ベース・カード請求確認修正版

【今回の根本修正】
「カード請求を確認した」は、月末チェック対象月と同じ月に
請求されたカードだけを見る方式をやめました。

代わりに、
「その月に使った明細が、実際に何月請求になるか」
を1件ずつ追跡します。

【2026年8月の例】
au PAY 8/23利用
→ 2026年10月請求へ追跡

apollostation 8/7利用
→ 2026年9月請求へ追跡

apollostation 8/23利用
→ 2026年10月請求へ追跡

8月の月末チェックでは、
これら3つの請求先をまとめて確認します。

【未確定請求】
請求状態が「未確定」でも、
表示されている請求額と登録済み明細が一致していれば
「確認済み」の対象にできます。

後で確定額が変わった場合は、
保存した確認署名と差が出るため自動で再確認へ戻ります。

【月移動】
8月を確認済み
→ 9月へ移動
→ 10月へ移動
→ 8月へ戻る

としても8月の確認済みは維持します。

単なる月移動では確認を解除しません。

【画面表示】
月末チェックに、例えば
au→10月 ✅未確定 / Apollo→9月 ✅確定 / Apollo→10月 ✅未確定
のように利用月から請求月への追跡状況を表示します。
