家計・オデッセイ資金管理アプリ v2.4

【v2.4変更点】
・auじぶん銀行の残高0円を最優先で認識
・au PAYゴールドの「お支払金額 0円」を最優先し、日付・利用可能額を除外
・イオンカードの「未確定 / ¥--」を0円候補として扱い、「10月以降」の10を除外
・3画面とも専用OCR範囲をさらに狭くして誤認識を低減

【使い方】
1. 「画像の種類」は自動判定のままにする
2. 「画像を選ぶ」で銀行・カードのスクショを複数選択
3. 自動判定結果と金額を確認
4. 正しければ「認識結果を反映」
5. 誤っている画像だけ種類を指定し、1枚で再実行

※ OCRは誤認識する可能性があります。必ず反映前に表示金額を確認してください。


[v2.4] 実際の7種類の銀行・カード画面に合わせてOCRを再調整。八十二銀行の支店/口座番号除外、auじぶん/au PAYの判定強化、利用可能額やポイントの除外、0円の正常認識を改善。
