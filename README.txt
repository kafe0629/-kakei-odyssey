家計・オデッセイ資金管理 v6.4
ホーム「オデッセイ購入ナビ」追加版

【新機能】
ホーム画面の上部に、採用中の車プランをコンパクト表示します。

表示内容:
・採用中の頭金 / 返済期間
・借入額
・月返済
・金利
・購入に必要な資金
  = 頭金 + 生活防衛資金
・現在のみずほ残高から購入まであといくら
・あと何か月
・購入時期目安
・購入資金の達成率 / 進捗バー

【現在条件でのテスト】
{
  "採用中プラン": "頭金250万円 / 8年",
  "月返済": 38260,
  "購入必要資金": 4000000,
  "現在みずほ": 159012,
  "購入まであと": 3840988,
  "残り月数": 77,
  "達成率": 4.0
}

現在の採用中プランでは、
・頭金 250万円
・8年
・月返済 約38,260円
・購入に必要な資金 400万円
・現在のみずほ 159,012円
・あと 3,840,988円
・毎月5万円純増なら あと77か月
として表示します。

「車計画を詳しく見る」を押すと、下部タブを操作せず車計画へ直接移動します。
