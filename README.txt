家計・オデッセイ資金管理 v6.2
頭金増額プラン統合版

【新機能】
自動おすすめ判定の中に「頭金を増やすプラン」を追加しました。

現在予定の頭金を基準に、
・現在予定のまま
・+25万円
・+50万円
・+75万円
・自由入力
を比較します。

おすすめ月返済額を上限にしながら、
7年 → 8年 → 9年 → 10年の順で、
できるだけ短い返済期間を自動選択します。

各案で表示:
・採用頭金
・返済期間
・月返済
・借入額
・利息総額
・生活防衛資金込み必要みずほ額
・現在残高からの不足
・到達目安
・購入時期
・購入後の家計余力

「この頭金プランを採用」で
頭金とローン期間を一緒に設定へ反映できます。

【重要修正】
メインの「おすすめプランを採用」は、
最低必要頭金が現在予定の頭金より少なくても、
現在予定の頭金を勝手に減らしません。

現在設定のテスト:
{
  "0": {
    "down": 2000000,
    "years": 9,
    "monthly": 39673
  },
  "250000": {
    "down": 2250000,
    "years": 9,
    "monthly": 37062
  },
  "500000": {
    "down": 2500000,
    "years": 8,
    "monthly": 38260
  },
  "750000": {
    "down": 2750000,
    "years": 7,
    "monthly": 39890
  }
}

月4万円を上限にした場合:
・頭金200万円 → 9年 / 月約39,673円
・頭金225万円 → 9年 / 月約37,062円
・頭金250万円 → 8年 / 月約38,260円
・頭金275万円 → 7年 / 月約39,890円
