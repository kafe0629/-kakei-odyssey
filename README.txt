家計・オデッセイ資金管理 v6.7.1
バッジ獲得 達成演出版

【新機能】
生活防衛資金・購入資金のバッジ条件を新しく達成した時に、
「🎉 バッジ獲得！」の達成演出を1回だけ表示します。

対象:
・防衛25%
・防衛50%
・防衛75%
・生活防衛資金達成
・購入資金50%
・購入資金75%
・購入必要資金達成

【重複防止】
一度表示したバッジは端末内に記録し、
ページ再表示やアプリ再起動で同じ演出を繰り返しません。

【更新時の安全処理】
v6.7.1へ初めて更新した時点ですでに獲得済みのバッジは
「既達成」として登録します。
そのため、過去に達成したバッジの演出が更新直後に
まとめて表示されることはありません。

【複数同時達成】
残高を大きく更新して複数バッジを同時に超えた場合は、
全て獲得済みとして記録し、最も高いバッジの演出を1回だけ表示します。
