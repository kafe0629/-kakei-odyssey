家計・オデッセイ資金管理 v6.7
貯金モチベーション追加版

【新機能】
ホームに「🔥 貯金モチベーション」を追加しました。

1. 次の小目標
   50万円 → 100万円 → 150万円 → 200万円 → 250万円
   → 300万円 → 現在の購入必要資金
   の順で、いま一番近い目標と「あと何円」を表示します。

2. 連続貯金
   月次の「みずほ月末残高」を使い、
   前月より残高が増えた月の連続数を表示します。
   記録が2か月未満なら「判定待ち」と表示し、推測しません。

3. 今月の前進
   前月末残高と現在のみずほ残高を比較し、
   今月いくら増えたかを表示します。
   月5万円の予定ペースに対して何か月分進んだかも表示します。

4. 達成バッジ
   ・生活防衛資金 25%
   ・生活防衛資金 50%
   ・生活防衛資金 75%
   ・生活防衛資金 達成
   ・購入資金 50%
   ・購入資金 75%
   ・購入必要資金 達成
   を自動判定します。

【現在値のテスト】
{
  "current": 159012,
  "nextGoal": 500000,
  "nextGoalRemain": 340988,
  "nextBadge": "防衛25%",
  "nextBadgeAmount": 375000,
  "nextBadgeRemain": 215988,
  "purchaseProgressPct": 4.0
}

現在のみずほ159,012円なら、
・次の小目標: 500,000円
・あと: 340,988円
・次のバッジ: 生活防衛資金25%（375,000円）
・バッジまであと: 215,988円
と表示されます。
