家計・オデッセイ資金管理アプリ v3.0

【主な内容】
・v2.9までの家計管理・OCR自動入力機能を維持
・八十二銀行、みずほ銀行、auじぶん銀行、楽天銀行の残高管理
・au PAYゴールド、イオンカード、apollostationの請求管理
・未引落し携帯料金の確保
・次の給料日（毎月15日）までの生活費確保を考慮した資金管理
・自由資金、追加貯金可能額の自動計算

【iPhoneでアプリのように使う方法】
1. index.html / manifest.json / sw.js / README.txt を同じGitHubリポジトリにアップロードします。
2. GitHub Pagesで公開します。
3. iPhoneのSafariで公開URLを開きます。
4. 共有 →「ホーム画面に追加」を選びます。

入力内容は端末のブラウザ内に保存されます。定期的にアプリ内のバックアップ機能からJSON保存をおすすめします。
