家計・オデッセイ資金管理アプリ v1.4

【v1.4変更点】
・ホームの「カード・口座 支払管理」にスクリーンショットOCRを追加
・iPhoneの写真/ファイルから複数画像を選択可能
・八十二銀行、みずほ銀行、auじぶん銀行の残高候補を抽出
・au PAYゴールド、イオン、apollostationの請求額候補を抽出
・認識結果を確認してから一括反映
・au PAYカードが請求未確定の場合、利用枠と残額から算出した使用額は参考表示のみ（次回請求には自動反映しない）
・OCRはTesseract.jsを使い端末内で処理。初回利用時はOCRライブラリ/日本語データのダウンロードに通信が必要
・OCR誤認識に備えて、反映後は必ず金額を確認してください

【更新方法】
GitHubリポジトリの index.html / manifest.json / sw.js / README.txt を同梱ファイルで上書きし、Commit changesしてください。
GitHub Pages反映後、ホーム画面アプリを完全終了して再起動してください。
