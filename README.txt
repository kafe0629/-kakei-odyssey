家計・オデッセイ資金管理 v6.3.1
おすすめ固定 + 追加改善案版

【変更】
・採用した車ローンプランを「採用中プラン」として固定
・自動おすすめが勝手に別案へ切り替わらない
・v6.3で頭金250万円 / 8年を採用済みなら自動引継ぎ
・採用中を基準に追加改善案を表示

【追加改善案テスト】
{
  "採用中": {
    "頭金": 2500000,
    "期間": 8,
    "月返済": 38260
  },
  "もっと月額を下げる": {
    "頭金": 2500000,
    "期間": 9,
    "月返済": 34452
  },
  "もっと早く完済": {
    "頭金": 2500000,
    "期間": 7,
    "月返済": 43159
  },
  "頭金を増やして期間短縮": {
    "頭金": 2750000,
    "期間": 7,
    "月返済": 39890
  }
}

・月額を下げる: 頭金250万円 / 9年 / 約34,452円
・早く完済: 頭金250万円 / 7年 / 約43,159円
・頭金+25万円で期間短縮: 頭金275万円 / 7年 / 約39,890円

【固定解除】
「採用中プランを解除して再判定」で、
現在の頭金・期間は変えずに固定だけ解除できます。

【バックアップ】
採用中プランも正常バックアップ・安定版・JSONに含みます。

【維持】
v6.3までのカード、月次、請求月、光熱費、家賃、車計画等を維持。
