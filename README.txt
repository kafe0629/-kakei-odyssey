家計・オデッセイ資金管理 v7.2
操作性・月締めサマリー・給料日サイクル版

【重要：2つの期間を分離】
1. 月末締め
   1日〜月末
   → 「何にいくら使ったか」を見る家計簿・実績

2. 給料日サイクル
   15日〜翌14日
   → 「給与から次の給料日までどう回すか」を見る資金繰り

月末締めを15日に変更していません。
2つを別々に表示・計算することで、給料日が15日でも月次比較がズレません。

【ホーム：給料日サイクル】
表示:
・今回給与
・15日振り分け
・カード引落予定
・次の15日まで使える額
・サイクル利用実績
・次の給料日までの日数

15日振り分けには:
・貯金
・県民共済
・妻への家賃
・母への振込
・教育資金（開始月以降）
・NISA（開始月以降）
・振込手数料
を含めます。

2026年8月の既知実績例:
貯金 50,000
県民共済 2,500
妻家賃 45,000
妻振込手数料 110
母 20,000
母振込手数料 110
教育 0
NISA 0
→ 15日振り分け ¥117,720

2026/8/15〜9/14のカード引落例:
Apollo 2026年9月請求 ¥20,197

「次の15日まで使える」は、
現在の八十二銀行残高から未引落し・必要確保額を除いた金額です。
すでに支払ったものを給与から再度差し引く方式ではないため、
途中日でも二重計上しにくい設計です。

【明細一覧コンパクト化】
日付:
2026-08-23 → 08/23
詳細な日付は内部データではそのまま保持します。

ボタン・選択欄もiPhone向けに詰め、
1画面により多くの明細を表示します。
