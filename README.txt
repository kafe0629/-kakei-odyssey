家計・オデッセイ資金管理 v7.3.8
カード請求確認 状態保持修正版

【修正内容】
「カード請求を確認した」は月ごとの確認済み状態として保存します。

例:
8月で請求突合 2/2一致・差額0円
→ 8月を確認済みとして保存
→ 9月・10月へ移動
→ 8月へ戻る
→ チェックはそのまま維持

【安全策】
単なる月移動ではチェックを外しません。
ただし同じ月の
・請求額
・請求状態
・登録明細合計
・登録明細件数
が実際に変わった場合は、その月の自動確認だけ解除します。

つまり「月を変えたから消える」はなくし、
「データを変えたから再確認が必要」は残します。

【維持機能】
・v7.3.7 請求月ナビ同期
・母への振込済み同期
・au PAY明細OCR
・店名補正
・給料日サイクル
・振込手数料
・apollostation値引き管理
