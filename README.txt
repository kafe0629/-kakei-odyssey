家計・オデッセイ資金管理 v7.3.7
請求月ナビ・月末チェック同期修正版

【修正1：請求月の月送り】
v7.3.6で、
上部は「請求月 2026年10月」なのに
利用日ベース・請求日ベース・請求カード欄が
2026年8月の表示のまま残ることがありました。

v7.3.7では、
前月・次月・次の請求あり・対象月直接入力のすべてで
最初に対象月を1つに固定してから、
・利用月3カード合計
・請求月3カード合計
・au PAY / イオン / apollostation請求
・請求突合
・月末チェック
を同じ月で再描画します。

詳細集計の一部でエラーが起きても、
旧月の数字を画面に残さないフェイルセーフを追加しています。

【修正2：母への振込】
月末チェックの母振込判定を、
「15日振込・手数料管理」の母データと完全に同じ参照元に統一しました。

例:
2026-08 母 20,000円 / 振込済み
→ 月末チェックも「15日 振込済み ¥20,000」

2026-09 母 20,000円 / 未振込
→ 月末チェックも「15日 未振込 ¥20,000」

月が違えば状態もその月に合わせて正しく変わります。

【修正3：対象月を明示】
月末チェックリストに
「対象月：2026年8月（2026-08）」
のように表示します。
利用月/請求月を移動した時に、どの月を確認しているか分かります。
