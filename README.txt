家計・オデッセイ資金管理 v7.3.6
月末チェック同期修正版

【母への振込】
支払・振込アラートでは「振込済み」なのに
月末チェックでは「未振込」になる不整合を修正。

15日振込管理と母への振込予定を双方向で同期します。
古い保存データが食い違っている場合は、
初回起動時に新しい振込管理データを基準に整合します。

【カード請求確認】
対象カードの請求突合が全件一致し、
差額が0円なら「カード請求を確認した」を自動完了します。

例:
請求突合 2/2一致 / 差額 ¥0
→ ✅ 自動確認

後から請求額や明細が変わって差額が出れば、
自動完了は解除され、手動確認へ戻ります。
