家計・オデッセイ資金管理 v5.6
画面分離・ナビゲーション修正版

【修正内容】
・ホーム / 月次 / 車計画 / 予定 / 設定を完全に別ページとして表示
・ブラウザのHTML自動補正でsectionがmain外へ移動した場合、起動時に自動修復
・タブを押したとき対象ページだけactiveにする
・最後に開いていたページを端末内に保存
・ページ切替時はページ最上部へ移動
・v5.5のカード明細修正機能を維持
・v5.5の安定版バックアップ機能を維持
・v5.4の0円計算修正を維持
・保存済み家計データはそのまま引き継ぎ

【更新方法】
GitHub Pagesの
index.html / manifest.json / sw.js
を3つとも上書きしてください。

更新後、下部の
ホーム → 月次 → 車計画 → 予定 → 設定
を順番に押し、それぞれ別画面が表示されることを確認してください。
