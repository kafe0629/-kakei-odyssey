家計・オデッセイ資金管理アプリ v1.6

【v1.6変更点】
・銀行スクリーンショットOCRを改善
・みずほ銀行アプリの MIZUHO ロゴ表示に対応
・八十二銀行アプリで銀行名が出ず「屋代支店」と表示される画面に対応
・OCR自動判定が失敗した場合に「画像の種類」を指定して読み取れる機能を追加
・残高画像では通貨記号・「円」・カンマ付き金額から残高候補を抽出
・従来どおり、認識結果を確認してから反映

【今回の画像での想定】
・みずほ：159,012円
・八十二：93,870円

【使い方】
1. まず「自動判定」で画像を読み取る
2. 失敗したら「画像の種類」で八十二銀行残高 / みずほ銀行残高などを選択
3. 画像は1枚ずつ選ぶ
4. 認識候補を確認して「認識結果を反映」

【更新方法】
GitHubリポジトリの index.html / manifest.json / sw.js / README.txt を同梱ファイルで上書きし、Commit changesしてください。
GitHub Pages反映後、ホーム画面アプリを完全終了して再起動してください。
