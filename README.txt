家計・オデッセイ資金管理 v7.0.2
カード明細「コンビニ / タバコ」分割版

【今回の追加】
ホーム → カード明細 → 登録済み明細に「分割」ボタンを追加しました。

コンビニで
・タバコ
・飲み物 / 食べ物 / 日用品など普通のコンビニ買い物
を同時にカード決済した場合、1つのカード明細をカテゴリだけ分割できます。

例:
ローソン ¥1,000
→ タバコ ¥600
→ コンビニ ¥400

カード利用額:
¥1,000のまま

月次カテゴリ:
タバコ ¥600
コンビニ ¥400

【重要】
カード請求・締めサイクル・au PAY利用月額は元の明細金額を使います。
カテゴリ集計だけ分割するため、カード請求との金額はズレません。

【入力方法】
1. ホーム
2. カード明細の「登録済み明細」
3. 対象明細の「分割」
4. タバコ金額を入力
5. 「残りをコンビニに入れる」
6. 合計が元明細と一致したら「分割を保存」

「その他」も必要なら金額を入力できます。

【安全機能】
・分割合計 ≠ 元明細 → 保存不可
・月締め済みの明細 → 分割変更不可
・分割中は通常カテゴリ選択を無効化
・自己診断で壊れた分割データを検出
・分割解除可能
・分割データはauTransactions内なので既存JSON/安定版バックアップへ自動保存
