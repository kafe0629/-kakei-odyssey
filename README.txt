家計・オデッセイ資金管理 v5.9
利用月・請求月 デュアル管理版

【今回の追加】
月次ページで「利用月」と「請求月」を切り替えられるようにしました。

■ 利用月
従来どおり、利用日ベースで集計します。
・食費
・日用品
・コンビニ
・ガソリン
・外食・娯楽
・タバコ
・その他
・au PAY / イオン / apollostation 利用額
「3カードを月次欄へ反映」も従来どおり利用月データを使います。

■ 請求月
カード会社からその月に請求・引落される金額を別管理します。
・au PAY
・イオン
・apollostation
それぞれ「未登録 / 未確定・見込み / 確定 / 支払済」を保存できます。

請求月では以下を自動計算します。
・3カード請求合計
・八十二銀行から引落予定
  （イオン + apollostation）
・auじぶん銀行から引落予定
  （au PAY）
・確定済み請求
・未確定・見込み

【利用月と請求月は混ぜません】
たとえばapollostationは、
利用した月の家計分析と、実際に7日に請求される月を別々に管理します。

【支払管理から同期】
「支払管理から同期」を押すと、
次回確定請求と現在の未確定額を対応する請求月へ割り当てます。
支払管理を保存した時にも請求月を同期します。

2026-08-27時点の確認値では、
2026年9月:
・apollostation 確定請求 20,197円
・請求合計 20,197円

2026年10月:
・au PAY 未確定見込み 149円
・apollostation 翌月未確定 2,769円
・請求合計 2,918円
