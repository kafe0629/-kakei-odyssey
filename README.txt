家計・オデッセイ資金管理 v3.4 PWA版

【GitHub Pagesへの更新方法】
1. このZIPを解凍します。
2. GitHubリポジトリのルートに次の4ファイルをアップロード／上書きします。
   - index.html
   - manifest.json
   - sw.js
   - README.txt
3. GitHub Pagesの公開URLをSafariで開きます。
4. Safariの共有ボタン →「ホーム画面に追加」を選びます。

【更新後も古いバージョンが表示される場合】
Safariで公開URLを開いてv3.4表示を確認してください。
ホーム画面版だけ古い場合は、一度ホーム画面の旧アプリを削除し、Safariから再度「ホーム画面に追加」してください。

データはブラウザ内（localStorage）に保存されます。更新前にアプリのバックアップ機能でJSONを保存しておくことを推奨します。
