家計・オデッセイ資金管理 v6.5
家計精度向上＋カード月次完全自動同期版

【追加した機能】
1. 購入後の車総維持費
   ローン、保険、ガソリン、自動車税、車検、整備・消耗品、
   タイヤ、駐車場を月額換算して表示。

2. 購入時期の実績ペース
   月次で保存したみずほ月末残高から、
   予定ペース / 実績直近3回 / 実績直近6回 / 月7万円
   の購入時期を比較。

3. 車購入GO判定
   頭金＋防衛資金、購入後の月余力、八十二銀行の支払余力、
   採用中ローンプラン等から
   「購入GO / もう少し / まだ待つ」を表示。

4. 車資金の段階表示
   ①生活防衛資金
   ②車の頭金
   の順で進捗を表示。

5. カード月次 完全自動同期
   ・読み取ったカード明細 → 利用日ベースで利用月へ自動反映
   ・OCR/支払管理の請求 → 請求月へ自動反映
   ・光熱費、みずほ月末残高は自動同期で上書きしない
   ・請求調整は利用月から除外
   ・利用月/請求月の自動同期は個別にOFF可能

【注意】
現金支出をカード明細の食費・日用品等と同じ月次欄へ
手入力で足したい場合は「利用月自動同期」をOFFにしてください。
