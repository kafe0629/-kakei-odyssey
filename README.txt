家計・オデッセイ資金管理 v7.1
明細管理・月締め強化版

【1. カード明細の検索・絞り込み】
ホームの登録済み明細で以下を絞れます。
・店名/メモ検索
・利用月
・カード（au PAY / イオン / apollostation）
・カテゴリ
・確認状態（要確認 / 確認済み / 分割済み）

最大100件まで表示し、表示件数と全件数を表示します。

【2. 要確認明細】
新しく画像から読み込んだ明細は「要確認」になります。
内容を確認して「確認済みにする」を押すと完了します。

自動的に要確認になる例:
・新しく読み込んだ明細
・コンビニ明細（タバコ混在確認）
・カテゴリがその他の旧明細
・店名が空/不明
・分割合計が壊れている明細

カテゴリを手動変更した場合:
→ 確認済みに自動変更

タバコ/コンビニ分割を保存した場合:
→ 確認済みに自動変更

カード種別を変更した場合:
→ 再確認が必要になります。

【3. タバコ月次比較】
月次レポートに
・タバコ 今月
・タバコ 前月比
を追加しました。

カード明細の分割で「タバコ」にした金額と、
現金で登録したタバコを合算します。

例:
前月 ¥600
今月 ¥400
→ 前月比 −¥200

【4. カード欄の表示改善】
登録済み明細のカード/カテゴリ選択欄を再調整しました。
iPhoneの狭い画面でも「apollostation」が以前より確認しやすい幅・文字サイズにしています。

【5. 月締め前の安全チェック】
従来の月末チェックに自動項目を追加しました。

・カード明細の要確認が0件
・振込済み分の実手数料を確認済み

要確認明細が残っている場合:
→ 月締め不可

振込済みなのに実手数料が未入力の場合:
→ 月締め不可

月締め欄には
「まだ締めない方がよい項目」
を具体的に表示します。

【6. 自己診断修正】
店舗名チェックが transaction.memo を正しく見るよう修正しました。
当月の要確認カード明細数も自己診断へ追加しました。
