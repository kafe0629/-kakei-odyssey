【今回の修正】
ホーム最上部に残っていた旧350万円目標を廃止し、
採用中の車プランと同じ購入必要資金で統一します。

購入必要資金 =
採用中の頭金 + 生活防衛資金

現在の採用中プラン:
・頭金 2,500,000円
・生活防衛資金 1,500,000円
・総目標 4,000,000円

みずほ現在残高 159,012円の場合:
・購入まであと 3,840,988円
・月50,000円純増 → 77か月
・購入目安 → 2033年1月
・進捗 → 約4.0%

ホーム最上部の
・採用プラン購入まで
・購入目安
・購入進捗バー
と、オデッセイ購入ナビが同じ数字になります。

【設定】
「みずほ総目標」は
「頭金＋防衛資金・自動」に変更し、読み取り専用にしました。
頭金または生活防衛資金を変更して保存すると、
総目標も自動更新されます。

【車プラン変更】
採用中ローンプランを変更した場合も、
頭金に合わせてみずほ総目標を即時更新します。
