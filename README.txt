家計・オデッセイ資金管理 v7.4.3

【修正1：妻との精算】
・妻への家賃振込が「振込済み」
・入力済みのガス/電気/水道がすべて「精算済」
この2条件で「妻との精算が完了」を自動チェックします。
未完了の場合は月末チェックリストの「妻との精算が完了」を直接タップして完了操作もできます。

【修正2：apollostation OCR文字】
ETCのOCR文字を整形します。
例:
ETC 東 日 本 ( 岩 浅 っ 館林 ) 0 円
→ ETC東日本（岩槻→館林）
ETC 東 日 本 (館林 っ 浦和 本 線 ) 0 円
→ ETC東日本（館林→浦和本線）
ETC 東 日 本 (川口 JCT っ 草加 第 二 ) 。
→ ETC東日本（川口JCT→草加第二）
セルフ草加弁天町のレギュラーも読みやすい店名へ補正します。

【修正3：カテゴリ】
・「高速道路・ETC」を追加
・ETC東日本/NEXCO/高速道路は高速道路・ETCへ自動分類
・セルフ/レギュラー/ハイオク/軽油はガソリンへ自動分類
・手動で変更したカテゴリは自動分類で上書きしません
