家計・オデッセイ資金管理 v7.0.1

【重要修正】
v7.0では振込管理欄の状態・手数料を変更すると、
inputイベントで画面全体が再描画され、入力直後に初期値へ戻る問題がありました。
v7.0.1では入力中は再描画せず、合計プレビューだけ更新する方式へ変更しました。

そのため以下がすべて変更できます。
・振込額
・状態
・予定手数料
・実手数料
変更後に「この月の振込・手数料を保存」を押すと確定します。

【実績補正】
2026年8月 妻への家賃: 45,000円 / 振込済み
2026年8月 教育資金: 対象なし / 0円
2026年9月 教育資金: 対象なし / 0円
教育資金開始月: 2026年10月
2026年10月以降: 本人分10,000円/月を基準

妻の産休中家賃50,000円のルールは将来月用として維持し、
8月実績だけ45,000円で上書きしています。
