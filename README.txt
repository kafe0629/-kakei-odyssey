家計・オデッセイ資金管理 v4.1 PWA

GitHub Pages のリポジトリ直下へ以下4ファイルを上書きしてください。
- index.html
- manifest.json
- sw.js
- README.txt

v4.1の主な追加
- レシート写真・スクリーンショットの端末内OCR
- 合計金額と店名候補の自動入力
- 買い物の分類（食費・日用品・外食/娯楽・タバコ・その他）
- ホームで登録したau PAY買い物履歴を月次へ自動集計
- 「月次欄へ反映」で食費等とau PAY利用額へコピー
- v4.0までのカード・口座・OCR・車計画・バックアップ機能を維持

レシートOCRは誤認識する場合があります。登録前に金額と店名を確認してください。

更新後も古い版が出る場合：
1. SafariでGitHub Pages URLを直接開く
2. v4.1表示を確認
3. ホーム画面の旧PWAを削除
4. Safariの共有→ホーム画面に追加
