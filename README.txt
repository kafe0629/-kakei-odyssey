家計・オデッセイ資金管理アプリ v3.3

【主な内容】
・v3.2までの家計管理・OCR自動入力機能を維持
・給料日前（今日→次の15日）と次サイクル（次の15日→翌月15日）を分けて表示
・給料日前の不足額と補充期限を表示
・八十二銀行に残すべき最低額を表示
・次サイクル1日あたり生活費を個別設定可能（0円なら現在の1日生活費を引き継ぎ）
・次サイクルの生活費・固定費・カード請求・その他支出を確保
・「本当の余裕資金」と「安全に貯金へ移せる額」を自動計算

【iPhoneでアプリのように使う方法】
1. index.html / manifest.json / sw.js / README.txt を同じGitHubリポジトリにアップロードします。
2. GitHub Pagesで公開します。
3. iPhoneのSafariで公開URLを開きます。
4. 共有 →「ホーム画面に追加」を選びます。

入力内容は端末のブラウザ内に保存されます。定期的にアプリ内のバックアップ機能からJSON保存をおすすめします。
