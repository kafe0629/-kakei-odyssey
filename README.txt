家計・オデッセイ資金管理 v6.3
頭金増額プラン おすすめタイプ自動判定版

【追加】
頭金増額の4プランにタイプを自動表示します。

・資金余裕型
  追加頭金が最も少なく、購入資金を残しやすい案

・月額最優先
  月返済が最も軽い案

・バランス型
  頭金・月返済・返済期間・利息のバランスを取りやすい案

・早期完済型
  返済期間が最も短い案

【現在条件での判定】
{
  "200万円": "資金余裕型",
  "225万円": "月額最優先",
  "250万円": "バランス型・総合おすすめ",
  "275万円": "早期完済型"
}

現在条件では、
頭金250万円 / 8年 / 月約38,260円
を「バランス型・総合おすすめ」と表示します。

【新しい操作】
頭金増額セクション上部に
「頭金増額の総合おすすめ」を表示します。
「総合おすすめを採用」で、頭金250万円・8年など
現在の判定結果をそのまま設定へ反映できます。
