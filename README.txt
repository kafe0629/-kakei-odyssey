家計・オデッセイ資金管理 v7.0
資金予定・安全チェック＋振込手数料管理版

【1. 支払・振込アラート】
ホームで15日の振込状況を確認します。
・妻への家賃
・母への振込（8〜11月）
・教育資金
15日を過ぎた「未確認 / 未振込」は警告します。

【2. 次の15日に必要なお金】
八十二銀行から15日に必要な資金を集約します。
・貯金
・県民共済
・家賃中継
・妻への振込手数料
・母への振込＋手数料
・教育資金＋手数料
・NISA（開始月以降）

母への振込は15日の振り分けへ統合し、
次サイクル固定費からは外して二重計上を防止しました。

【3. 振込手数料管理】
妻・母・教育資金ごとに月単位で
・振込元金
・予定手数料
・実手数料
・状態（未確認 / 未振込 / 振込済み）
を保存できます。

手数料は推測しません。
設定の標準予定手数料は初期値0円＝未設定です。
実手数料は振込後に銀行明細を確認して入力してください。

妻への家賃の手数料は、みずほ貯金を削らないよう
八十二→自分みずほの入金必要額にも先に加算します。

母への未振込分は、元金だけでなく予定手数料も
八十二銀行の確保額へ含めます。

【4. 月次レポート】
「振込手数料」を独立表示します。
記録分の月支出 =
生活費 + 家賃 + 自動車保険 + NHK + 母への実振込 + 実振込手数料

教育資金の元金は自分の資産内移動なので支出に含めず、
振込手数料だけを支出として計上します。

【5. アプリ自己診断】
設定画面で自動確認:
・店舗名空欄 / undefined
・カード請求突合差額
・締め済みスナップショット不足
・振込済みなのに実手数料未確認
・予定手数料未設定
・15日経過後の振込状況未確認
・カード利用月額と明細集計の差
・30日以上バックアップなし
・主要設定の異常0円

【6. バックアップ】
振込状態・手数料 transferRecordsV70 を
正常バックアップ / 安定版 / JSONへ保存します。
月締めにも transferSummary を保存します。
